# 成功标准

## 工程体验

- 用户能从模板或空白画布搭建链路。
- 修改参数后可以快速运行并听到结果。
- 工程保存为 YAML，可版本管理。

## 系统正确性

- 编译器检查类型、通道、时钟域、Task 边界和平台约束。
- 动态运行与生成运行的关键输出一致。
- 实时路径无动态内存、阻塞锁或文件 IO。

## 部署质量

- 生成工程独立构建。
- 生成的代码结构清晰，无隐藏运行时依赖。
- 嵌入式宿主可以按平台接入真实 IO。
