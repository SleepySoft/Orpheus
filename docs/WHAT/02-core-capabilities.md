# 核心能力

## 编辑

- 拖放节点、连接类型化端口、参数编辑、注释和撤销重做。
- 子组件嵌套、可变端口、替代组、控制链路可视化。

## 运行

- PC 动态 Runtime 实时或离线运行。
- 静态执行计划、时钟域、多速率、多 Task 与异步桥。
- 参数实时更新、探针回读、波形/频谱/矩阵观测。

## 部署

- 生成独立 C/C++ 工程。
- Windows 实时宿主与嵌入式 DSP 骨架。
- 平台解析、替代组激活和设备适配层。

详细能力矩阵见 [[../HOW/reference/what-legacy|原始 WHAT 全文]]。
