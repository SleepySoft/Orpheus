# 数据与控制需求

## 数据面

- 类型化音频端口：通道数、采样率、块长和方向。
- 音频数据不跨 Task 直接共享；异步桥接必须显式建模。
- 观测数据通过 Probe 返回 UI，不阻塞实时线程。

## 控制面

- 参数具有类型、范围、更新策略和签名影响。
- 控制链路可以把一个组件的读回值驱动到另一个组件参数。
- Bridge 支持远程调参、探针上报和消息协议。

详细设计见 [[../HOW/06-control-and-protocol|HOW：控制与协议]]。
