# 术语与文档导航

## 关键术语

| 术语 | 含义 |
|---|---|
| 组件 | 有 manifest、端口、参数和 C ABI 实现的可复用单元 |
| 图 | 组件实例、连接、参数、Task 和工程配置的集合 |
| Plan | 编译产物，描述拓扑、调度、内存和元数据 |
| Bridge | 本机、串口或其他访问端点的统一控制/观测通道 |
| Task | 独立时钟或速率域的执行入口 |
| Probe | 从运行系统读取观测值和数据的通道 |
