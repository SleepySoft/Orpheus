# 愿景与用户

Orpheus 的定位是：**在电脑上像搭积木一样构建音频系统，并生成像手工嵌入式工程一样干净的代码。**

核心用户包括：

| 用户 | 核心诉求 |
|---|---|
| DSP 学习者 | 理解滤波器、采样率、延迟、信号流 |
| 算法研究员 | 快速验证 EQ、混响、分频、降噪、重采样 |
| PC 音频用户 | 搭建可听、可调、可分享的音效链 |
| 嵌入式工程师 | 部署固定内存、可审查、可交叉编译的代码 |
| 教师 | 组织可交互实验和自动检查 |

完整原始需求见 [[../HOW/reference/what-legacy|原始 WHAT 全文]]。
