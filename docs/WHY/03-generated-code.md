# 为什么强调生成干净代码

音频产品最终要落在真实设备上。解释器或黑盒运行时在 PC 上方便，但在嵌入式场景中会带来内存、时序、审查和工具链成本。

Orpheus 的生成路径强调：

- 生成可读、可审查、可版本管理的 C/C++ 工程。
- 静态展开拓扑，减少运行期不确定性。
- 保留 PC 验证和嵌入式部署之间的一致性。
- 生成代码不依赖 Python 或编辑器运行时。

策略见 [[../HOW/07-code-generation|HOW：代码生成与平台适配]]。
