# 为什么选择可视化组件模型

音频链路天然是图：信号从源到处理器，再到输出；控制信号和数据观测也经常跨节点流动。文本配置容易隐藏结构，胶水代码容易让拓扑和实现耦合。

可视化组件模型带来三个关键收益：

1. 结构直观：拓扑、方向、速率和平台边界更容易检查。
2. 复用明确：组件是独立实现，工程只是实例和连接。
3. 生成可靠：图可以被编译器展开、校验并转换为固定代码。
