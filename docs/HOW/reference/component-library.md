# 通用组件库：归属、命名与分类

## 归属先于分类

组件库依次显示可折叠的工程子组件、工程定制组件，再显示通用组件。
固定业务布局、实例数量或车型协议的原子组件应放入所属工程，通过相对路径imports加载，
不能仅改成一个通用名字后继续留在公共库。

BAF的`call_snapshot`和`conditional_call`已迁入研究工程`baf_skeleton/native/`：
前者固定40项增益目标，拆为驾驶员/乘客各20项；后者固定54路输入、22路返回、80项读回。
源码、头文件和CMake一起迁移，由工程Registry参与动态构建及代码生成。
稳定组件ID不变，归属由manifest来源判定，不由`orpheus.builtin`等ID前缀猜测。

源自外部模型不等于工程专用。可配置表、矩阵尺寸或声道映射，且不要求某个工程的固定业务协议，
仍可作为通用构件；实现来源和容量上限保留在详细说明中。

## 九个功能分类

通用库使用平铺功能类，不再以“基础/高级”划分难度，或因audio/bulk类型另建同职责目录。
工程导入组件仍允许自己的多级分类。

| 类别 | 范围 |
|---|---|
| 输入与输出 | 文件、声卡、宿主/嵌入式音频边界、测试信号与占位/丢弃端 |
| 驱动与缓冲 | 驱动入口、跨任务缓冲、组块/拆块、延迟、采样率转换 |
| 路由与混音 | 音频/数组通道合并拆分、选路、矩阵混音、M/S声道组合 |
| 增益与动态 | 增益渐变、声道平衡、静音、限幅、音量控制和幅度调制 |
| 滤波与均衡 | FIR/IIR、二阶节与级联、音调和索引均衡 |
| 频域与分析 | FFT、分帧/重叠相加、频谱布局、功率与相干统计、电平与波形观测 |
| 自适应与降噪 | NLMS、FxLMS及多参考多输出自适应滤波 |
| 数学与控制 | 标量/数组运算、查表、状态保持、包络与序列锁存 |
| 平台与通信 | 访问桥、串口、平台钩子及SPORT/TDM集成边界 |

## 命名与说明原则

- 显示名优先描述实际作用，不保留原模型块名造成的功能暗示；ID继续作为稳定引用。
- 同类构件标明区别：共享/独立历史、静态/平滑系数、数据表/参数表、音频/数组。
- 说明先写输入、处理和结果，再交代单位、状态、调用关系及适用边界。
- 不把统计叫降噪、把组块叫分频、把矩阵混音叫3D、把dB换算叫桥接。
- 测量与代理估计要区分，不能把RMS称为标准LUFS，或把NLMS残差直接认定为非线性失真。
- 不因元数据整理改变端口ID、参数ID、签名、数值顺序、状态或驱动传播声明。

## 需要特别区分的构件

| 稳定ID末段 | 当前显示名 | 关键边界 |
|---|---|---|
| downrate | 音频组块器 | 采样率不变，写满不自动触发消费者，输出截断驱动 |
| resample | 整数倍降采样 | N:1平均或选点；选点需外置抗混叠 |
| rational_resample | 有理倍采样率转换 | L/M多相FIR；不能以组块替代重采样 |
| rate_sync | 双路缓冲合流 | 同采样率FIFO对齐后相加，不是异步Task桥 |
| matrix_mul | 系数矩阵混音 | 紧凑BULK矩阵乘音频向量，无内置系数渐变 |
| input_mixer_3d | 矩阵混音与输出增益 | BULK固定行步长32，加共享输出增益，无3D处理 |
| slc_matrix_mul | 插值与平滑矩阵混音 | 每样本更新系数，目标可由表插值或序列锁存产生 |
| bulk_db | 线性与dB换算 | 保持shape与节拍，无缓冲或跨域桥接 |
| spectral_reduce | 频谱聚合统计 | sum/mean/min/max归约，没有减噪声谱 |
| sleeping_beauty | 声道分组平衡渐变 | 可配置查表与四组增益映射，不测量响度 |
| biquad | 二阶滤波器（Biquad） | 单段二阶；不是“双二阶”或两段级联 |
| biquad_bank | 双段二阶滤波器 | 固定两段，区别于iir_bank可配置级数 |
| probe_rms / probe_peak | RMS/峰值电平表 | 全块全部通道合并为一个读回值，不是逐通道数组 |
| sweep_record | 扫频响应记录 | 根据时间线记录首通道RMS，激励须来自上游 |
