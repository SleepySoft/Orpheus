# 通用组件库：归属、命名与分类

## 归属先于分类

组件库依次显示可折叠的工程子组件、工程定制组件，再显示通用组件。
固定业务布局、实例数量或车型协议的原子组件应放入所属工程，通过相对路径imports加载，
不能仅改成一个通用名字后继续留在公共库。

BAF的`call_snapshot`和`conditional_call`已迁入研究工程`baf_skeleton/native/`：
前者固定40项增益目标，拆为驾驶员/乘客各20项；后者固定54路输入、22路返回、80项读回。
源码、头文件和CMake一起迁移，由工程Registry参与动态构建及代码生成。
稳定组件ID不变，归属由manifest来源判定，不由`orpheus.builtin`等ID前缀猜测。

源自外部模型不等于工程专用。可配置表、矩阵尺寸或声道映射，且不要求某个工程的固定业务协议，
仍可作为通用构件；实现来源和容量上限保留在详细说明中。

## 九个功能分类

通用库使用平铺功能类，不再以“基础/高级”划分难度，或因audio/bulk类型另建同职责目录。
工程导入组件仍允许自己的多级分类。

| 类别 | 范围 |
|---|---|
| 输入与输出 | 文件、声卡、宿主/嵌入式音频边界、测试信号与占位/丢弃端 |
| 驱动与缓冲 | 驱动入口、跨任务缓冲、组块/拆块、延迟、采样率转换 |
| 路由与混音 | 音频/数组通道合并拆分、选路、矩阵混音、M/S声道组合 |
| 增益与动态 | 增益渐变、声道平衡、静音、限幅、音量控制和幅度调制 |
| 滤波与均衡 | FIR/IIR、二阶节与级联、音调和索引均衡 |
| 频域与分析 | FFT、分帧/重叠相加、频谱布局、功率与相干统计、电平与波形观测 |
| 自适应与降噪 | NLMS、FxLMS及多参考多输出自适应滤波 |
| 数学与控制 | 标量/数组运算、查表、状态保持、包络与序列锁存 |
| 平台与通信 | 访问桥、串口、平台钩子及SPORT/TDM集成边界 |

## 命名与说明原则

- 显示名优先描述实际作用，不保留原模型块名造成的功能暗示；ID继续作为稳定引用。
- 同类构件标明区别：共享/独立历史、静态/平滑系数、数据表/参数表、音频/数组。
- 说明先写输入、处理和结果，再交代单位、状态、调用关系及适用边界。
- 不把统计叫降噪、把组块叫分频、把矩阵混音叫3D、把dB换算叫桥接。
- 测量与代理估计要区分，不能把RMS称为标准LUFS，或把NLMS残差直接认定为非线性失真。
- 不因元数据整理改变端口ID、参数ID、签名、数值顺序、状态或驱动传播声明。

## 节点字段复制

右侧参数面板的节点 ID、显示名、组件类型为只读文本字段，点击或 Tab 聚焦后选中，
可用 Ctrl+C 或右键菜单复制；显示名仍通过“重命名”修改，不直接编辑稳定 ID 或类型。
有文字选区或焦点位于文本输入控件时，画布复制粘贴快捷键不拦截浏览器操作；
没有文字选区时，画布选中节点的 Ctrl+C / Ctrl+V 继续复制节点和内部连线。

## 完整接口审查与按需显露

设计决定见 [ADR-0003](../../ADR/0003-declared-interfaces-and-host-audio.md) 与后续
[ADR-0004](../../ADR/0004-parameter-lifecycle-and-visibility.md)。
参数页列出组件定义声明的参数、BULK 资源与逐个数据端口，不因 readback 隐藏资源。
右侧参数面板可收起；“独立窗口”把同一配置面板移入可拖动、缩放的浏览器窗口，
继续同步当前节点、参数编辑、观测和显露选择，同时释放画布空间。
关闭窗口或点击“收回侧栏”返回主界面；浏览器拦截弹窗时明确提示，原面板保持可用。
初始化配置、运行期参数、观测/交付状态、Buffer 和端口分组均可折叠，
通道数等通用配置在同组内优先排列，独立窗口内按可用宽度自动分列。
节点 TODO 区块默认折叠，包括已有待办和占位节点；标题仍显示未完成数量，点击后可查看与编辑。
窗口位置、尺寸及折叠状态只属于当前界面会话，不写入工程或执行计划。
音频输入和输出分别显示自己的格式、通道数、块长与采样率。
签名沿 `maps_to` 递归到实际原子实例，由后端复用编译器解析；
各层无需复制格式，同一定义的不同实例也不会共用错误的参数覆盖结果。
参数页显示最终引用来源；外层显式字段仅是约束，冲突时显示实际签名和具体诊断，
正式编译拒绝冲突。无法解析时显示原因，不回退为 f32 或工程全局块长。
自动音频输入的块长取自身连接实际交付的长度，显式配置不会被自动覆盖；
桥接入口使用消费者侧交付长度，未连接输入不继承其它输入的处理量子。
字面量、自身参数和显式 Task 表达式表示配置，只有输入依赖或未配置的继承字段需要推导；
已知类型、样本格式与直接参数值立即显示，复杂表达式仍由后端求值。
连接差异按类型、样本格式、通道数、采样率、交付块长及数据布局/帧结构校验；
失配线标红，悬停可查看两端值，配置和连线都保留，由用户修改后恢复匹配。
WAV 输出采样率仅在配置为 0 时跟随输入，非零配置不再被自动覆盖。
详见 [ADR-0006](../../ADR/0006-configured-port-contracts.md)。
画布、宿主 Buffer 摘要和公开音频候选复用同一结果，候选支持继续引用内部复合端口。
复合定义视图采用该定义的公开默认值，不把某个实例的覆盖值当作定义本身。
只读预览 API 消费未保存快照，不要求图已可执行，不保存工程、签名副本或执行计划；
拖动及显露变更不重新请求，切换视图或修改参数会取消并隔离旧响应。
新增复合端口只需 `id/direction/maps_to`；保存不再补写 `audio/f32`，
既有显式约束仍保留并校验。详见 [ADR-0005](../../ADR/0005-recursive-port-signature-source.md)。
宿主绑定的端口及对应存储按同一个逻辑 Buffer 展示，并说明供数来源和交付状态。
参数默认不显示在画布上，公开映射也不自动显示或禁止隐藏。
初始化配置（`restart_required` 或 `affects_signature`）在启动前注入，
运行后修改需重新准备；主动显示时采用灰色区域和“初始化”标记，不作为运行期控制端口。
运行期参数主动显示后，橙色方块仍只表示显式允许的控制连接能力，不代表所有公开参数均可连线。
复合组件内部显露的运行期公开参数保留橙色导出引线，输入向左、输出向右引出到节点外沿，
不生成覆盖参数文字的另一侧引线；初始化公开配置不使用这种控制引线。

用户选择“显露”才在画布绘制相应参数/Buffer 接口。只有存在实际控制连线的参数强制保持可见；
已连接音频端口和公开导出音频端口仍保持可见，避免幽灵连接。
取消参数显露不删除外层 `maps_to` 或配置入口，不改变参数值。
这种强制可见不覆盖用户自己的选择。显露选择保存在布局旁文件的
`node_ui[视图][节点]`，分为 `exposedParameters`、`exposedPorts`、`exposedBulkSlots`；
缺省与空数组均表示未主动选择，命名空间独立，不进入算法参数或执行计划。
工程内复合视图的显露保存在工程布局，不因视图选择修改公共组件定义。
只读组件定义也允许调整这种工程显示覆盖，不因定义只读而禁止显露选择。

完整审查不等于所有接口都能实时设置。显式 access、kind、bindable/control_source
和更新策略共同限定能力；普通复合公开配置参数不再自动授权控制输入。
宿主输入连上游后提示“上游供数，禁止宿主写入”；数据交付不产生驱动。

本轮界面不实现设备采集或 PCM 提交。宿主绑定存储禁止直接用普通 BULK 面板写入；
ready/valid 是交付协议状态，界面展示实际观测，不作为设计时参数编辑、导入或预设。
保存时 ready 的初始化值为 false，不把运行时就绪状态持久化成下一次启动的假输入。
完整 PCM 交付由统一宿主端口 API 完成，并要求与实际 Task 串行。

## 需要特别区分的构件

| 稳定ID末段 | 当前显示名 | 关键边界 |
|---|---|---|
| downrate | 音频组块器 | in只追加小块，tick独立读取完整大块并交付；采样率不变，欠载/未读覆盖明确报错 |
| block_split | 音频拆块器 | in只发布大块，tick独立读取小块并交付；不预填静音，欠载/未读覆盖明确报错 |
| resample | 整数倍降采样 | in按N:1平均或选点写入，tick独立读取交付；跨调用分组，选点需外置抗混叠 |
| rational_resample | 有理倍采样率转换 | L/M多相FIR；不能以组块替代重采样 |
| rate_sync | 双路缓冲合流 | 同采样率FIFO对齐后相加，不是异步Task桥 |
| matrix_mul | 系数矩阵混音 | 紧凑BULK矩阵乘音频向量，无内置系数渐变 |
| input_mixer_3d | 矩阵混音与输出增益 | BULK固定行步长32，加共享输出增益，无3D处理 |
| slc_matrix_mul | 插值与平滑矩阵混音 | 每样本更新系数，目标可由表插值或序列锁存产生 |
| bulk_db | 线性与dB换算 | 保持shape与节拍，无缓冲或跨域桥接 |
| spectral_reduce | 频谱聚合统计 | sum/mean/min/max归约，没有减噪声谱 |
| sleeping_beauty | 声道分组平衡渐变 | 可配置查表与四组增益映射，不测量响度 |
| biquad | 二阶滤波器（Biquad） | 单段二阶；不是“双二阶”或两段级联 |
| biquad_bank | 双段二阶滤波器 | 固定两段，区别于iir_bank可配置级数 |
| probe_rms / probe_peak | RMS/峰值电平表 | 全块全部通道合并为一个读回值，不是逐通道数组 |
| sweep_record | 扫频响应记录 | 根据时间线记录首通道RMS，激励须来自上游 |

本次审查覆盖123份公共manifest，其中122项可见；修订94个显示名，补齐所有缺失说明，
保留详细数值契约和实现来源。两个BAF专用组件不再出现在通用分类中。
