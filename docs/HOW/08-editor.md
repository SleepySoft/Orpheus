# 编辑器与交互

UI 使用 React 和 React Flow。

## 状态

- 视图状态负责画布位置、选区和展开。
- 工程状态负责节点、边、参数和配置。
- 组件目录来自后端 registry。

## 大模型载入反馈

首次连接和切换工程时显示载入面板：读取工程列表 → 读取工程、组件与布局 →
转换视图 → 初始化画布。等待后端时显示已完成请求数和累计用时，不用估算百分比；
转换阶段按实际完成的视图/节点计数更新，并分批让出主线程供界面刷新。

画布节点完成尺寸测量后才结束载入。期间暂停编辑和自动保存，避免旧画布被误操作；
失败时退出面板并显示错误，保留原工程。已失效或卸载的请求会中止，不覆盖后续载入结果。

## 扩展

- 参数控件走 `widgets.js` 注册表。
- 节点本体走 `nodeWidgets.js` 注册表。
- 控制边、替代组和 Bridge 投影由专用组件处理。

组件 UI 设计见 [[reference/component-ui|组件自定义 UI]]。
