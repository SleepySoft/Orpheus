# 编辑器与交互

UI 使用 React 和 React Flow。

## 状态

- 视图状态负责画布位置、选区和展开。
- 工程状态负责节点、边、参数和配置。
- 组件目录来自后端 registry。

## 大模型载入反馈

首次连接和切换工程时显示载入面板：读取工程列表 → 读取工程、组件与布局 →
转换视图 → 初始化画布。等待后端时显示已完成请求数和累计用时，不用估算百分比；
转换阶段按实际完成的视图/节点计数更新，并分批让出主线程供界面刷新。

画布节点完成尺寸测量后才结束载入。期间暂停编辑和自动保存，避免旧画布被误操作；
失败时退出面板并显示错误，保留原工程。已失效或卸载的请求会中止，不覆盖后续载入结果。

## 单页面编辑权

不支持协同编辑。同一服务的整个工作区只有一个可写页面，避免不同工程写回同一
共享组件定义时互相覆盖。第一个页面自动申请编辑权，其余页面只读，仍能浏览、
切换视图、选择节点和查看参数；参数独立窗口与所属主页面共享编辑权。

编辑权采用 30 秒租约，每 10 秒续租。关闭时尽力主动释放；崩溃、断网或后台计时器
被暂停时，租约按服务端单调时钟自动过期，不依赖清理定时器。续租失败或本地发现
过期时停止编辑和自动保存，保留页面中的未保存内容，不自动抢回编辑权。

只读页面可点击「接管并刷新」，确认后撤销旧令牌、取得新令牌，重新读取工程、
组件、布局和节点笔记，全部加载成功后才允许编辑。工程笔记面板也会重新载入。
接管不会合并未保存内容；需要保留的内容须先复制。加载失败时释放新租约，保持只读。

服务端校验每个写请求，包括工程/共享组件、笔记、上传、编译生成和运行控制。
接管与写请求串行：已进入处理的写请求先结束，再接管并读取最新状态；
排队的旧保存、旧续租和旧释放都不能影响新持有者。旧页面最迟在下一次续租或
写请求被拒绝时显示失权；即使界面尚未更新，也无法写入。

这是单服务进程内的防误操作机制，不是认证系统，也不限制直接修改磁盘或 CLI。
部署约束与外部 HTTP 客户端用法见 [运行与部署](./11-operations.md)。

## 扩展

- 参数控件走 `widgets.js` 注册表。
- 节点本体走 `nodeWidgets.js` 注册表。
- 控制边、替代组和 Bridge 投影由专用组件处理。

组件 UI 设计见 [[reference/component-ui|组件自定义 UI]]。
