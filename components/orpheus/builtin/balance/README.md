# orpheus.builtin.balance — 左右平衡

## 功能

把多通道音频按“偶数通道 = 左组、奇数通道 = 右组”分成两个声道组，分别施加互补增益，实现左右（或前后、上下）声像平衡偏移。常用于立体声、前后声场或双区扬声器的能量再分配。

一句话理解：它不改变总响度，只是把声音从一侧“推”向另一侧。

## 参数

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `balance` | float | 0.0 | 平衡位置。`-1.0` 全左/前组静音，`0.0` 居中，`+1.0` 全右/后组静音。 |
| `channels` | int | 2 | 通道数，必须 ≥2。改变后需重新编译。 |
| `ramp_ms` | float | 50.0 ms | 增益变化斜坡时间，避免切换时产生咔哒声。 |

### `balance` 的真实含义

组件内部把通道按索引分组：

- 偶数索引通道（0、2、4…）归为“左侧 / 前组”
- 奇数索引通道（1、3、5…）归为“右侧 / 后组”

当 `balance > 0` 时，前组增益从 1 降到 `1 - balance`，后组保持 1；当 `balance < 0` 时，后组增益降到 `1 + balance`，前组保持 1。因此总能量大致守恒，不会出现某一边突然变响的问题。

## 端口

- `in`: 输入音频，`channels` 通道。
- `out`: 输出音频，通道数与输入相同。

## 注意事项

- 通道数必须是偶数分组意图才有意义；如果只有 2 通道，就是普通立体声左右平衡。
- 斜坡时间仅在参数变化时生效； prepare 时目标与当前增益立即对齐，所以第一次运行不会有渐变。
- 属于实时安全组件，process 内无内存分配、无三角函数。

## 典型用法

```
signal_gen (2ch sine) ──► balance ──► wav_out
```

把 `balance` 从 `0.0` 改成 `-1.0`，声音会从右声道慢慢移到左声道；再改回 `0.0` 又会平滑回到中间。配合 `channels: 22` 可用于多扬声器阵列的左右声场微调。
