# 音频缓冲驱动源

将宿主输入 Buffer 与驱动入口组合显示。音频输出端口只绑定数据；
「驱动连线」模式从源本体发起特殊入口箭头，不传输 PCM，也不显示执行连接点。
计算数据链默认续传驱动，组件上的彩色圆点标记归属；解耦端口的声明会截断传播。

宿主交付顺序：

1. 用 BULK 接口完整写入 `samples`，元素数为 `channels × block_size`。
2. 将 `ready` 设为 `true`。
3. 调用该源对应的图入口；组件消费新块，清除 `ready`，再续调下游。

源码与宿主缓冲接口共用实现，支持动态加载与独立生成。
不连接声卡、不读取文件、不创建定时器，也不自动生成输入。
未提交新块就推进会明确返回处理错误，并累计 `missing_blocks`。
无图输出时仍消费新块并续调，不能把它当作“不消费的查看操作”。

通道数由参数配置，块长与采样率使用工程/入口时间基准。
固定容量为 8192 个 f32；配置超容量明确报错。宿主必须串行完成提交与调用，
不能并发写处理中的数据。多入口交接需要用户另外配置合适的 Buffer。

对应示例：`examples/buffer_source_demo.yaml`。它是宿主供数入口示例，
不是无需宿主即可播放的声卡/WAV 工程。
