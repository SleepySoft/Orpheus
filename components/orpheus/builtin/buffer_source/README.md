# 音频缓冲驱动源

宿主提交完整交错f32的samples并设置ready后，由自身Task入口推进；
复制完成后算法显式交付1号音频out，不根据下游连接修改调用频率。
它不创建线程、不自动触发，也不等待或补齐吞吐。

宿主交付顺序：

1. 用 BULK 接口完整写入 `samples`，元素数为 `channels × 节点配置帧数`。
2. 将 `ready` 设为 `true`。
3. 推进自身Task；组件消费新块，清除ready，再交付音频out。

本包与host_audio均通过独立脚本生成，不保留旧共享宿主实现。
本组件自身是Task时钟源，不声明由另一个Source调用的输入口；
需要外部纯Task/分频源触发宿主缓冲时，使用host_audio的tick入口。
不连接声卡、不读取文件、不创建定时器，也不自动生成输入。
未提交新块就推进会明确返回处理错误，并累计 `missing_blocks`。
NULL输出仍消费并交付；零帧不推进、不交付。
下游失败不回滚已消费的块。reset清空物理缓冲、ready及缺块计数。

samples外部资源绑定audio_storage私有存储，形状为
`[config:frames, param:channels]`，固定物理容量8192个f32，支持双Bank。
拒绝配置零帧、超容量、非零初始交付状态、不匹配的处理量子、
不足输出容量及输出与整个State重叠；配置失败保持旧State。
宿主必须串行完成提交与调用，
不能并发写处理中的数据。多入口交接需要用户另外配置合适的 Buffer。

连接上的every/phase不参与接口调用，非默认值明确拒绝；
需要分频时使用真实触发分频组件及算法调用点，不隐式跳过数据。

对应示例：`examples/buffer_source_demo.yaml`。它是宿主供数入口示例，
不是无需宿主即可播放的声卡/WAV 工程。
