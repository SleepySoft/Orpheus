# orpheus.builtin.interp_lut — 查表插值

## 功能

一维线性插值查表器：给定一组 `(x_axis, y_axis)` 数据点，对输入 `x` 进行插值得到 `y`。音频本身原样直通，主要用于控制信号链路的“映射函数”——例如把车速、噪声级、旋钮位置等非线性映射成目标增益或阈值。

## 参数

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `x_axis` | string | "0, 1" | 查询表横坐标，逗号分隔。 |
| `y_axis` | string | "0, 1" | 查询表纵坐标，逗号分隔。 |
| `x` | float | 0.0 | 当前输入值，可实时设置。 |
| `y` | float | 0.0 | 当前插值结果（readback，只读）。 |
| `history` | string | "[]" | 最近的 `y` 值历史（readback，只读）。 |
| `channels` | int | 1 | 音频通道数，改变后需重新编译。 |

### `x_axis` / `y_axis` 的真实含义

两条列表定义了一个分段线性函数 `y = f(x)`。例如：

```yaml
x_axis: "0, 20, 80, 120"
y_axis: "0, 0.1, 0.6, 1.0"
```

表示：

- 车速 0 → 增益 0
- 车速 20 → 增益 0.1
- 车速 80 → 增益 0.6
- 车速 120 → 增益 1.0

中间值按线性插值；小于最小 `x` 取第一个 `y`，大于最大 `x` 取最后一个 `y`。

### `x` 与音频的关系

该组件的 `in/out` 音频端口只是让它能挂在信号链里；实际插值计算只依赖 `x` 参数。通常把上游 `level_detect` 的 `level` 或外部控制值写入 `x`，再读取 `y` 作为其他组件的参数。

## 端口

- `in`: 输入音频，`channels` 通道（直通）。
- `out`: 输出音频，与输入完全一致。

## 注意事项

- `x_axis` 和 `y_axis` 长度以较短者为准；多余的点会被忽略。
- 修改 `x_axis` / `y_axis` 后需要重新编译。
- `x` 可以实时变化，每个 process 块都会重新计算 `y`。
- 实时安全，process 内无内存分配、无三角函数。

## 典型用法

```
noise_level_detect ──► (y as gain target)
signal_gen ──► gain(gain_db = -interp_lut.y * 20) ──► out
```

用噪声电平查表得到一个 0~1 的抑制量，再把它映射成 dB 衰减值控制 `gain`，实现按噪声自动调节音乐响度。
