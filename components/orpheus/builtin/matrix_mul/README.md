# orpheus.builtin.matrix_mul — 矩阵乘法

## 功能

把输入音频向量 `in[cols]` 乘以一个 `rows × cols` 的常数矩阵，得到输出向量 `out[rows]`。用于通道混音、下混、上混、解码矩阵等场景，例如把 2 路输入混成 6 路环绕声，或把多路麦克风加权合并。

## 参数

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `rows` | int | 2 | 输出通道数（矩阵行数），改变后需重新编译。 |
| `cols` | int | 2 | 输入通道数（矩阵列数），改变后需重新编译。 |
| `matrix` | string | "1, 0, 0, 1" | 矩阵系数，行优先逗号分隔。 |

### `matrix` 的排列方式

矩阵按行优先填充：

```
out[0] = m00*in[0] + m01*in[1] + ...
out[1] = m10*in[0] + m11*in[1] + ...
```

`matrix` 字符串中的第 `r * cols + c` 个数就是 `m[r][c]`。

示例：2 输入 → 6 输出

```yaml
rows: 6
cols: 2
matrix: 1,0,0,1,0.5,0.5,0.7,0.3,0.3,0.7,0,0
```

表示：

- 输出 0 = 输入 0
- 输出 1 = 输入 1
- 输出 2 = 0.5 × 输入 0 + 0.5 × 输入 1
- 输出 3 = 0.7 × 输入 0 + 0.3 × 输入 1
- ...

如果矩阵元素数量不足，剩余位置填 0；如果全空，则自动使用单位矩阵（输入 `i` 直通到输出 `i`）。

## 端口

- `in`: 输入音频，`cols` 通道。
- `out`: 输出音频，`rows` 通道。

## 注意事项

- 矩阵元素是**线性增益**，不是 dB。如需 dB，请先用外部工具换算成线性值。
- 该组件是“无状态”的纯矩阵乘法，每一帧独立计算，适合代码生成路径完全展开。
- 修改 `matrix` 后需要重新编译；运行时不能热更新矩阵。
- 如果输出通道数多于输入，新通道由矩阵定义；如果少于输入，则实现下混。

## 典型用法

```
stereo (2ch) ──► matrix_mul(rows=6, cols=2,
                            matrix="1,0,0,1,0.5,0.5,0.7,0.3,0.3,0.7,0,0")
             ──► surround_processor
```

把立体声上混成 6 通道伪环绕声，再交给后级处理。
