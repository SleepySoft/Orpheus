# orpheus.builtin.matrix_mul — 系数矩阵混音

## 功能

把输入音频向量 `in[cols]` 乘以一个 `rows × cols` 的常数矩阵，得到输出向量 `out[rows]`。用于通道混音、下混、上混、解码矩阵等场景，例如把 2 路输入混成 6 路环绕声，或把多路麦克风加权合并。

## 参数

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `rows` | int | 2 | 输出通道数（矩阵行数），改变后需重新编译。 |
| `cols` | int | 2 | 输入通道数（矩阵列数），改变后需重新编译。 |
| `matrix` | string | "1, 0, 0, 1" | 矩阵初值，行优先逗号或空白分隔；非空默认文本不随尺寸自动改写。 |

### `matrix` 的排列方式

矩阵按行优先填充：

```
out[0] = m00*in[0] + m01*in[1] + ...
out[1] = m10*in[0] + m11*in[1] + ...
```

`matrix` 字符串中的第 `r * cols + c` 个数就是 `m[r][c]`。

示例：2 输入 → 6 输出

```yaml
rows: 6
cols: 2
matrix: 1,0,0,1,0.5,0.5,0.7,0.3,0.3,0.7,0,0
```

表示：

- 输出 0 = 输入 0
- 输出 1 = 输入 1
- 输出 2 = 0.5 × 输入 0 + 0.5 × 输入 1
- 输出 3 = 0.7 × 输入 0 + 0.3 × 输入 1
- ...

如果矩阵元素数量不足，剩余位置填 0；如果全空，则自动使用单位矩阵（输入 `i` 直通到输出 `i`）。

初值最多 1024 项、32767 UTF-8 字节，前 `rows*cols` 项参与运算，
其余物理存储不作为有效 BULK 范围暴露。非法数值、非有限值、
超出有限 float 范围、空项、尾随逗号或超容量明确拒绝，
不再写零跳过垃圾；非法 prepare 候选保留原矩阵。
仍先由 `strtod` 读入再转为 f32，逐列执行 f32 乘法及累加，不改变运算顺序。

## 端口

- `in`: 输入音频及驱动入口，`cols` 通道。
- `out`: 输出音频及 1 号驱动出口，`rows` 通道。

每次有效输入到达均同步交付，同一 Task 的重复到达分别处理。
零帧不交付；输入不足、输入输出重叠或输出覆盖矩阵存储明确拒绝。
接口配置经独立脚本生成壳，手写算法保存在 `user/algorithm.c`。

## 注意事项

- 矩阵元素是**线性增益**，不是 dB。如需 dB，请先用外部工具换算成线性值。
- 音频帧间没有递推历史，但实例持有可更新的矩阵；reset 将活动矩阵恢复为单位阵。
- 修改初始化文本需要重建；运行期可通过同名 `matrix` BULK 槽整组更新 `rows*cols` 项，
  使用双缓冲在调用边界生效。初始化文本不作为活动系数的回读，请使用 BULK 读取。
- 如果输出通道数多于输入，新通道由矩阵定义；如果少于输入，则实现下混。

## 典型用法

```
stereo (2ch) ──► matrix_mul(rows=6, cols=2,
                            matrix="1,0,0,1,0.5,0.5,0.7,0.3,0.3,0.7,0,0")
             ──► surround_processor
```

把立体声上混成 6 通道伪环绕声，再交给后级处理。
