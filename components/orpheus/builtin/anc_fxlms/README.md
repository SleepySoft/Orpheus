# 主动降噪（ANC）FxLMS 组件说明与原理

> **组件 ID** `orpheus.builtin.anc_fxlms` · 类型：前馈自适应主动噪声控制（Feedforward ANC）
> 采用更新规则：**Filtered-x Least Mean Squares (FxLMS)**。
>
> 本文按“它在做什么 → 为什么这样做 → 怎么调”的逻辑给你讲清楚。

---

## 1. 主动降噪在做什么

被动隔音（如耳机的密封耳罩）靠物理封装抑制低频噪声，但低频波长长、封装很难做好。
**主动降噪（ANC）**换一个思路：先用麦克风捕获噪声，再由扬声器播放一个
**幅度相同、位相相反**的信号，两者在人耳处叠加、相互消除。

其核心前提：
- 你想消除的位置（耳道）处，噪声与你控制的反相信号要靠得足够近，才能算数叠加。
- 噪声是随环境变化的，所以要用**自适应滤波器**不断跟踪并更新反相信号，而不是死的固定系数。

---

## 2. 前馈与反馈两种架构

| 类型 | 麦克风位置 | 特点 |
|---|---|---|
| **前馈 Feedforward** | 外部参考麦（朝向噪声源） | 提前感知噪声，消除频范更宽；但要求参考麦位置好、得到“时间先量” |
| **反馈 Feedback** | 误差麦（就在耳道内） | 对位置不敏感、更稳定；但多限于周期性/低频噪声 |

**本组件实现前馈。** 它用两个麦克风：
- `x`：外部参考麦信号（噪声），要提前捕获噪声。
- `d`：误差麦信号（耳道内残余），是算法的对象。

---

## 3. FxLMS 的数学模型（重点）

把噪声的传播分解为两条路径：
- **第一路径**：噪声源 → 耳道（你要消除的信号，用 `d` 约定）。
- **次级路径 Secondary path \(S(z)\)**：控制信号 → 扬声器 → 空间传播 → 误差麦。这是 FxLMS 与普通 LMS 的根本区别。

设自适应滤波器输出 \(y[n]=w^T x[n]\)，其中 \(x[n]\) 是参考信号的延迟向量：
- **控制信号**：扬声器播放 \(-y[n]\)（反相）。
- **达到误差麦的实际控制信号**：经次级路径后变成 \(-S(z)y[n]\)。
- **误差（残余）**：
  \[ e[n] = d[n] + S(z)y[n] \]
  消除理想：找到 \(w\) 使 \(S(z)y\) 恰好与 \(d\) 反相等幅，这样 \(e[n]\) 趋于零。

为什么不能直接用普通 LMS（\(w \gets w + \mu e x\)）？
因为控制信号被 \(S(z)\) 改变了。正确做法：把参考信号也先经“同样的次级路径模型”滤波，得到 filtered-x 信号 \(x'(n)=S(z)x(n)\)，然后：
  \[ w[n+1] = w[n] + \mu\, e[n]\, x'(n) \]

这就是 **FxLMS** 名字的来历：先对参考信号做“Filtered-by-\(S\)”，再用与 LMS 相同的形式更新。
没有它，更新方向就会因次级路径的位相偏移而错误，算法无法正常收敛。

### 本组件的次级路径模型

真实次级路径是一个 FIR（工厂测量得到）。为了教学简明，本组件用：
  \[ S(z) = g \cdot z^{-\Delta} \]
即“应益 \(g\) + 纯延迟 \(\Delta\) 个采样点”。它不完全真实，但能清晰地展示 FxLMS 的思路。

## 4. 参数说明

| 参数 | 默认 | 含义与调整建议 |
|---|---|---|
| `filter_length` | 128 | 自适应滤波器阶数。越大可描述越长的回声，但收敛更慢、计算更大。建议先排断预估延迟再选。 |
| `step_size` (μ) | 0.05 | 收敛速度 vs 稳定性的杆。过大—>挚动/发散；过小—>收敛很慢。一般 0.001~0.1。 |
| `leakage` | 1.0 | 泄漏因子（≤1）。低于 1 会让系数缓慢衰减，提升稳定性、避免安静时系数飘移。 |
| `eps` | 1e-6 | 正则化：避免参考能量为零时除零。 |
| `secondary_gain` | 1.0 | 次级路径模型赋益 \(g\)。根据实际扬声器增益调整。 |
| `secondary_delay` | 3 | 次级路径模型延迟 \(\Delta\)（采样点）。必须与真实控制路径延迟接近，否则降噪效果会变差。 |

**调参策略**：从小阶数、小 μ 开始验证能否收敛，再逐步加大。次级路径模型不准是降噪效果差的最常要原因。

---

## 5. 预测口（readback）

- `noise_reduction_db`：\(10\log_{10}(P_d/P_e)\)，正值越大表示除去越多噪声。
- `power_d`：误差麦平均功率（消除前到耳道的噪声）。
- `power_e`：残余平均功率（消除后）。
- `detail`：细节 JSON。

---

## 6. 用法示例

可用两个 `wav_in` 分别接 `x` 和 `d`（同一份噪声），`out` 接 `wav_out`，
看 `noise_reduction_db` 是否为正。真实场景下：
- `x` ← 外部参考麦（噪声）
- `d` ← 耳道内误差麦
- `out` → 扬声器

前馈要求参考麦提前捕获噪声（时间先量要大于次级路径延迟），吗则正略信息会超出延迟容量。

---

## 7. 教学小结

1. **FxLMS 的宅心**：把参考信号也先经次级路径模型滤波，再用它更新滤波器。
2. **次级路径模型必须准**：实际产品会实时测量，教学组件用 `gain+delay` 简化。
3. **低频好消、高频难**：高频波长短，稍有延迟偏差就破坏相位。常见 ANC 仅有效于 1kHz 以下。
4. **扬声器限幅**：不能无限放大反相信号，也是为什么 ANC 对小噪声有效、大噪声时主要靠被动隔音。
