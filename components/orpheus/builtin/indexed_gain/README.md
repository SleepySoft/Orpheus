# indexed_gain - 查表增益渐变

将 0..255 等外部索引通过自定义 dB 表转换为共享线性增益，并以逐样本指数 ramp 作用到多通道音频。支持 dB offset、最大增益、freeze、dB/s 或 ms 时长，以及独立的冷启动线性增益。

`apply_index_on_prepare=true` 时按索引初始化；设为 false 时使用 `initial_gain`，直到首次 `gain_index` 或 `gain_offset_db` 更新。`current_gain` 是标准只读控制源，可供后续控制链读取。

适用于外部模型中的表驱动 Volume；不绑定具体表或通道布局。

## 接口与数值契约

`in` 是驱动入口，每次实际调用直接交付 1 号 `out`。
索引与 dB 表是初始化文本，不是没有真实注册对象的 BULK 槽；
两表各 2048 字节、1～32 项，严格解析并要求等长、索引非递减。
允许重复端点（例如多个 255），非法项、超长表和非有限值明确拒绝，
不再静默截断或缩为较短表。

- 保留 `strtof` 解析、线性插值、叠加夹在 [-10, 0] 的偏移、
  应用最大 dB、最后 `powf(10, db/20)` 的次序。
  高于表末端的索引仍采用原算法的首项值；
  通常应把索引表覆盖到 255，不自动替换为末端夹取。
- 修改索引/偏移才重新计算斜坡。修改时间/速率不重算已有斜坡。
  每样本先乘指数系数，再处理所有通道；
  每次 process 末尾将剩余块数减一，最后一次输出后才吸附目标。
  块数按配置 block_size 推导，组件实际多次到达分别消耗一次，不做 Task 去重。
- 冻结同时停止逐样本递推和块计数；reset 仅取消斜坡，
  保留当前增益、参数和冻结状态。
- 保留有效零帧事件：不处理样本，但非冻结斜坡仍减一次块数并交付。
  下游失败不回滚已递推状态。精确原地合法，短载荷、
  部分重叠和 State 别名明确拒绝。
- `current_gain` 是真实只读探针；候选配置校验失败保留全状态。
  不能表示为有限 f32 的目标或斜坡计算明确返回错误。

独立 CLI 校验/生成后，算法只填充类型化输出并显式 emit；
回归见 `tests/indexed_gain_smoke.c` 和
`orpheus_core/tests/test_indexed_gain_interfaces.py`。
