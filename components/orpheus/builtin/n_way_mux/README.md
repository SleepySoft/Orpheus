# orpheus.builtin.n_way_mux — N 路输入选 1 路

## 功能

从 N 路输入中选择一路输出（多选一开关 / A-B 对比切换）。

- **输入路数 `inputs`**：决定输入引脚数量，引脚为 `in0`、`in1` … `in(N-1)`（可变引脚，改 `inputs` 后画布引脚即时刷新）。
- **`select` 选第几路**：整数，**从 1 数起**——`1` = `in0`，`2` = `in1`，依此类推。超出范围自动钳到 `[1, inputs]`。
- **平滑切换**：运行中改 `select`，输出按 `ramp_ms` 毫秒在新旧两路之间线性交叉淡化，无咔哒声；`ramp_ms = 0` 为立即切换。
- 未连接的引脚按静音处理（切换经过它时淡到无声）。

典型用法：效果链 A/B 对比（原始 vs 处理后的声音随时切换试听），见 `examples/mux_ab_compare.yaml`。

## 端口

| id | 方向 | 说明 |
|---|---|---|
| `in0..in(N-1)` | input | N 路候选输入，每路 `channels` 通道 |
| `out` | output | 当前选中的一路 |

## 参数

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `inputs` | int | 2 | 输入路数 1~32，决定引脚数；改动需重新编译 |
| `channels` | int | 2 | 每路通道数 1~32；改动需重新编译 |
| `select` | int | 1 | 选第几路输入（1=in0，2=in1 …）；可实时切换，自动平滑淡化 |
| `ramp_ms` | float | 20.0 | 切换淡化时长（毫秒），0=立即切换；改动需重新编译 |

## 实时安全

process 中无堆分配、无阻塞、无 IO；稳态（未在切换中）为整帧 memcpy。
