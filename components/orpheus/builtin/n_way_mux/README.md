# orpheus.builtin.n_way_mux — N 路输入选 1 路

## 功能

从 N 路输入中选择一路输出（多选一开关 / A-B 对比切换）。

- **输入路数 `inputs`**：决定输入引脚数量，引脚为 `in0`、`in1` … `in(N-1)`（可变引脚，改 `inputs` 后画布引脚即时刷新）。
- **`select` 选第几路**：整数，**从 1 数起**——`1` = `in0`，`2` = `in1`，依此类推。超出范围自动钳到 `[1, inputs]`。
- **`select_index` 按索引选路**：完整配置时负数表示使用 `select`，非负数优先；运行期设置该字段则直接选路，负数钳到第 0 路。`0` = `in0`、`1` = `in1`。两个字段规范化后回读同一路，支持完整 int32 请求而不发生加一溢出。
- **平滑切换**：运行中改选路，当前位置逐样本滑向目标，每相邻一路耗时 `ramp_ms` 毫秒；跨多路时依次经过中间路，不是只混合旧/新两路。`ramp_ms = 0` 为立即切换。
- 未连接的引脚按静音处理（切换经过它时淡到无声）。

典型用法：效果链 A/B 对比（原始 vs 处理后的声音随时切换试听），见 `examples/mux_ab_compare.yaml`。

## 端口

| id | 方向 | 说明 |
|---|---|---|
| `in0..in(N-1)` | input | N 路候选输入，每路 `channels` 通道 |
| `out` | output | 当前选中的一路 |

## 参数

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `inputs` | int | 2 | 输入路数 1~32，决定引脚数；改动需重新编译 |
| `channels` | int | 2 | 每路通道数 1~64；改动需重新编译 |
| `select` | int | 1 | 选第几路输入（1=in0，2=in1 …）；可实时切换，自动平滑淡化 |
| `select_index` | int | -1 | 0-based 输入索引；配置负值使用 `select`，运行期负值选第 0 路 |
| `ramp_ms` | float | 20.0 | 每相邻一路淡化时长（毫秒），0=立即切换；改动需重新编译 |
| `select_pos` | float | 0.0 | 只读当前位置（0起），reset 吸附到目标 |

## 接口驱动

`component.yaml` 的 `interfaces` 是唯一声明源，独立脚本生成 `generated/`，
手写实现位于 `user/algorithm.c`。
全部 `in0..in(N-1)` 都是 `process: true` 入口，每次真实到达独立处理当前可见候选，
由算法交付 1 号 `out`；多个输入同拍到达就有多次输出和位置推进，
不等待其它输入、不补调、不去重。候选尚未更新时读取其原有内容，
未连接候选为正零静音。工程须自行安排生产与交付顺序。

完整配置和运行期选路共用纯候选 `normalize` 钩子，同时提交钳位后的
`select` 与 `select_index`，不在可变 setter 中制造会被生成壳覆盖的假回读。
零帧仍交付事件，平滑模式不推进位置，立即模式保留吸附目标的语义；
下游失败不回滚已推进位置。拒绝不足载荷及输入/输出/状态重叠。
稳态逐位拷贝，不让未选分支的 NaN/Inf 参与计算。

## 实时安全

process 中无堆分配、无阻塞、无 IO；稳态（未在切换中）为整帧 memcpy。
