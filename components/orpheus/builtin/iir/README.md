# 直接型任意阶 IIR

1～16 阶归一化直接型 II 转置多项式滤波，1～64 通道；
不是二阶节级联。每通道保存独立历史，严格按 f32 乘法、加法、减法次序递推。

## 接口

- `in`：交错 f32 输入及驱动入口。
- `out`：同通道音频及 1 号驱动出口，每次非零到达同步交付。
- `channels/order/coefs_mode`：重建生效，模式为 `shared/per_channel`。
- `coefs`：紧凑初始化 CSV，每组为 `[b0…bN,a1…aN]`，a0 固定 1；
  shared 要求一组，per_channel 要求每通道一组。
- `initial_coefs_per_channel`：逐通道资源的初始化入口；
  per_channel 模式下非空值覆盖 `coefs` 的初值。
  shared 模式下也可预先初始化非活动逐通道存储，但不参与当前运算。
- `processing_enabled`：0 输出正零并冻结历史，1 正常处理。

两份初始化文本各最多 65535 UTF-8 字节，必须是完整、有限的逗号分隔 f32 数值，
允许数值两侧空白；长度不符、空项、尾逗号、非有限值和溢出明确拒绝。
纯候选失败保留旧参数、系数及历史。

## 运行期资源

两个外部 BULK 键均明确注册为独立存储，不互相别名：

| 键 | 有效容量 | 布局 |
|---|---|---|
| `coefs` | 33 | shared 模式使用，前 `2*order+1` 项为有效系数 |
| `coefs_per_channel` | `channels*33` | per_channel 模式使用，每通道固定 33 项步长 |

整组双缓冲更新在组件调用边界生效，不清除历史。
非活动槽的更新不影响当前模式；模式改变需要重建。
活动系数通过 BULK 读取，不以初始化文本回读冒充实时系数。
prepare 按紧凑初值展开为固定步长；reset 仅清历史，保留系数和使能值。

同 Task 多次到达分别推进历史，不等待、不去重；下游失败不回滚已处理历史。
零帧不推进也不交付。禁止输入输出重叠、短载荷及输出覆盖私有状态。
禁用时不要求输入数据，仍按每次实际到达交付正零。
process 内不分配内存、无 IO。

接口以 `component.yaml` 为事实源，经独立脚本生成壳，
手写实现保存在 `user/algorithm.c`。
