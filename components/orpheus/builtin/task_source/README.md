# 纯任务驱动源

只提供触发，不产生或分配 PCM。画布上的紫色标记直接显示编号 1 的 `out`
触发出口，连接目标声明的驱动入口；不使用节点本体的特殊连接点，也不依赖旧驱动开关。
目标的数据输入另行连接，可以完全没有音频输入。

宿主每次推进此 Task，只启动源；源实际调用一次 `orpheus_emit`，
同步完成 `out` 的直接下游子树。同口扇出按工程保存顺序执行，
后续组件自行交付，不恢复算法执行列表，不等待会合或去重。
纯触发即使上下文帧数为 0 也仍是一次事件；Delivery 不携带音频 Buffer，
帧位置、epoch 与时间线标志透传。下游错误直接返回，之后可继续调用。

`frequency_hz` 定义宿主推进的模型时间频率，默认 100 Hz，范围 1..192000 Hz，
必须精确整除工程时间基准采样率，不用取整改变频率。该参数需重启生效，
组件不在运行期接受直接 ABI 修改，也不自行创建定时器或线程。
PC 宿主可全速推进；按现实时间等待取决于宿主 pacing。
嵌入式由外部定时器、中断或应用绑定生成的 Task 入口。

实际分频应连接显式 `trigger_divider`，由它决定何时 emit；
接口级连接不再接受 `every/phase` 再次分频。绘图用 `drive_divide`
不参与执行、不补调、不管理 Buffer。
