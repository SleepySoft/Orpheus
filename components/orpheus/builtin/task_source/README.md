# 纯任务驱动源

只提供触发，不产生 PCM；画布上是紫色胶囊标记，没有普通音频端口。
开启「驱动连线」，从驱动源本体拖出特殊箭头，指向目标组件本体；没有可见执行连接点。
圆点标记声明的驱动归属，后续计算数据链默认传播，声明解耦的端口及控制关系不传播。
目标节点的数据输入另行连接，也可以完全没有音频输入。

`frequency_hz` 定义宿主推进的模型时间频率，不自行启动定时器或线程。
PC 宿主可全速推进；按现实时间等待取决于宿主 pacing。
嵌入式由外部定时器、中断或应用绑定生成的入口。
当前频率必须精确整除工程时间基准采样率，不用取整改变频率。

点击紫色箭头标签设置每 N 拍选择 1 拍及零基相位。
周期 4、相位 3 表示第 4、8、12……次上游触发时调用目标；
相位 0 则表示第 1、5、9……次。它不抽取 PCM 采样点，不管理 Buffer。
初始计数与计数复位沿用组件链式调用契约。

宿主仅启动源，源只调用直接下游；后续组件自行续调，不恢复算法执行列表。
底层标识仍为 `orpheus.builtin.task_source`，内部执行入口仍使用 Task，
但不把它画成普通计算节点，也不要求用户额外指定每个算法节点所属的 Task。

对应示例：`examples/trigger_source_demo.yaml`。
