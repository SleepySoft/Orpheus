# orpheus.builtin.fade — 前后衰减

## 功能

一种“频谱分频式”前后声场衰减控制：低频（低于 `crossover_hz`）保持原样通过，高频按 `fade` 参数衰减“后组”或“前组”通道的能量。常用于汽车音响中“前排优先”或“后排补声”等场景。

与 `balance` 的区别：`balance` 是全频段的左右能量再分配；`fade` 只影响高频，保留低频的座位间能量一致性。

## 参数

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `fade` | float | 0.0 | 衰减方向。`-1.0` 衰减前组高频，`0.0` 平直，`+1.0` 衰减后组高频。 |
| `crossover_hz` | float | 400 Hz | 分频点。低于此频率完全直通，高于此频率才参与 fade。 |
| `channels` | int | 4 | 总通道数，改变后需重新编译。 |
| `front_channels` | int | 2 | 前组通道数（从通道 0 开始数），剩余通道为后组。 |
| `ramp_ms` | float | 50.0 ms | `fade` 变化的斜坡时间。 |

### `fade` 的真实含义

- `fade >= 0`：前组高频保持 1，后组高频衰减到 `1 - fade`。
- `fade < 0`：后组高频保持 1，前组高频衰减到 `1 + fade`。

低频分量（由一阶低通提取）始终不乘 fade 增益，所以低频响度不受 fade 影响。

### `front_channels` 的坑

该参数只决定“前组”包含多少个通道，后组 = `channels - front_channels`。如果设置得比 `channels` 还大，组件会自动把它限制为 `channels - 1`；如果小于 1，则强制为 1。

## 端口

- `in`: 输入音频，`channels` 通道。
- `out`: 输出音频，通道数与输入相同。

## 注意事项

- 一阶低通分频的过渡带较宽，不适合需要陡峭分频的场景。如需精确分频，请前置 `iir_bank` 分频器。
- `fade` 是 smoothed 参数，可以在运行时实时拖动；`crossover_hz`、`front_channels`、`channels` 改后需要重新编译。
- 该组件不是“音量衰减”，高频能量减少后，整体响度会轻微下降，总能量并不守恒。

## 典型用法

```
full_mix (22ch) ──► fade(fade=0.3, front_channels=11, crossover_hz=400)
                  ──► speaker_delay ──► wav_out
```

在汽车 22 通道系统中，让后排 11 个通道的高频比前排略低，营造“皇帝位”前区聚焦感，同时保证低频在所有座位均匀分布。
