# orpheus.builtin.deinterleave — 音频通道拆分

## 功能

把一路 **N 通道交错**输入拆分为 N 路**单声道**输出（`out_ch[f] = in[f*N+ch]`）。

工作原理：依次从交错输入中提取第 `ch` 个通道，填满对应单声道缓冲后立即显式交付，
等待该出口的完整下游调用返回，再处理下一通道。未连接的出口不产生下游调用；
宿主可能仍为它提供丢弃缓冲，不保证零计算开销。

没有"选通道"参数，引脚 `out0..out(N-1)` 固定对应交错输入的通道 0..N-1；
需要哪一路就从对应引脚拉线。

### 可变引脚

`channels` 参数决定输出引脚数量（`count: param:channels`）：改成 4，画布上立即出现 `out0..out3`。改 `channels` 属于改签名（`affects_signature`），需重新编译。

接口配置是唯一事实源，独立脚本生成有界 `io->out[64]` 和实际 `out_count`；
出口局部编号为 `1 + ch`，算法调用 `emit_out(ctx, &io->out[ch])`。
编号本身不承诺先后，本算法选择按通道递增顺序交付。

## 端口

| id | 方向 | 说明 |
|---|---|---|
| `in` | input | 一路 N 通道交错输入（`channels: param:channels`） |
| `out0..out(N-1)` | output | N 路单声道输出，局部驱动编号 1..N |

## 参数

| 参数 | 类型 | 默认值 | 范围 | update_policy | 说明 |
|---|---|---|---|---|---|
| `channels` | int | 2 | 1~64 | restart_required（影响签名） | 通道数 = 输入交错通道数 = 输出引脚数 |

## 注意事项

- 输出引脚索引即通道索引：想取第 2 通道就连 `out2`，不是"第 2 条连线"。
- 数量、签名或类型异常时明确报错，不再用重复最后通道掩盖配置错误。
- 与 `interleave` 的样本排布互逆；运行时后者会被每次实际交付分别驱动，
  不等待所有通道到齐，不把多次调用合并成一次。
- 仅做样本搬运，不改采样率、块长，不增加算法延迟。

## 典型用法

```
device_in（立体声交错）──► deinterleave(channels=2) ──► out0 ──► 左声道处理链
                                                    └─► out1 ──► 右声道处理链
```

把多通道输入拆成独立单声道链分别处理；处理完用 `interleave` 合回多通道。

## 实时安全

process 内无堆分配、无锁、无 IO，纯样本拷贝循环；`realtime_safe: true`。
