# orpheus.builtin.deinterleave — 反交错器

## 功能

把一路 **N 通道交错**输入拆分为 N 路**单声道**输出（`out_ch[f] = in[f*N+ch]`）。

工作原理：对每个已连接的输出引脚 `ch`，从交错输入帧中取出第 `ch` 个样本写入该引脚的单声道缓冲；**未连接的输出引脚直接跳过**，不做任何计算。

本组件是 AWE 风格"**通道映射即连线**"的体现：没有"选通道"参数，引脚 `out0..out(N-1)` 固定对应交错输入的通道 0..N-1——你需要哪一路通道，就从对应引脚拉线；不关心的通道不连线即可，零开销。

### 可变引脚

`channels` 参数决定输出引脚数量（`count: param:channels`）：改成 4，画布上立即出现 `out0..out3`。改 `channels` 属于改签名（`affects_signature`），需重新编译。

## 端口

| id | 方向 | 说明 |
|---|---|---|
| `in` | input | 一路 N 通道交错输入（`channels: param:channels`） |
| `out0..out(N-1)` | output | N 路单声道输出，未连接的引脚被跳过 |

## 参数

| 参数 | 类型 | 默认值 | 范围 | update_policy | 说明 |
|---|---|---|---|---|---|
| `channels` | int | 2 | 1~32 | restart_required（影响签名） | 通道数 = 输入交错通道数 = 输出引脚数 |

## 注意事项

- 输出引脚索引即通道索引：想取第 2 通道就连 `out2`，不是"第 2 条连线"。
- 防御性行为：若运行时输出引脚数多于 `channels`（异常签名），越界引脚会重复输出最后一个通道（`sch = min(ch, N-1)`），正常工程中不会触发。
- 与 `interleave` 互为逆操作；仅做样本搬运，不改采样率、块长，零延迟。

## 典型用法

```
device_in（立体声交错）──► deinterleave(channels=2) ──► out0 ──► 左声道处理链
                                                    └─► out1 ──► 右声道处理链
```

把多通道输入拆成独立单声道链分别处理；处理完用 `interleave` 合回多通道。

## 实时安全

process 内无堆分配、无锁、无 IO，纯样本拷贝循环；`realtime_safe: true`。
