# orpheus.builtin.probe_waveform — 波形监视器

## 功能

示波器式监控组件：把输入音频原样直通，同时把第 0 通道的样本写入一个 1024 帧的环形缓冲（`PROBE_WAVEFORM_SAMPLES`）；每次探针上报时，把缓冲按时间顺序编码成 JSON 数组发给 UI 绘制波形。适合观察波形形状（正弦/方波/削波平顶）、确认信号通不通、调试滤波器相位失真等。

## 参数

| 参数 | 类型 | 默认值 | 范围 | 更新策略 | 说明 |
|---|---|---|---|---|---|
| `channels` | int | 2 | 1–32 | restart_required | 通道数，改变后需重新编译（影响端口签名）。 |
| `waveform` | string | `""` | — | immediate | 最近 1024 帧波形的 JSON 数组（readback，只读）。 |

### `waveform` 上报的是什么

- 环形缓冲里**最近 1024 帧**、仅**第 0 通道**的样本值，按时间先后排列（从最旧到最新），编码为 `[x0, x1, ...]` 的 JSON 字符串。
- 取值范围通常 −1~1；若看到一排紧贴 ±1 的平顶，说明信号削波了。
- 缓冲容量固定 1024 帧，与块长无关。48 kHz 下约为 21 ms 的时间窗；想看更长的波形请用 `probe_spectrum` 或导出 WAV。
- 采样按帧抽取（多通道时取每帧第 0 通道），不做降采样或触发同步——画面是连续滚动的，不是"锁定触发"的示波器。

## 端口

| 端口 | 方向 | 说明 |
|---|---|---|
| `in` | 输入 | 输入音频，`channels` 通道。 |
| `out` | 输出 | 输出音频，与输入完全一致（memcpy 直通，零延迟）。 |

## UI 行为

UI 节点本体（`nodeWidgets.js` 的 `ScopeWidget`）读取 `waveform` 探针画滚动波形画布：客户端保留历史快照，连续多次上报拼接成像 DAW 一样滚动的波形，而不是每次刷新跳到新窗口。宿主对 STRING readback 参数以 `PROBE_JSON` 协议行上报。

## 注意事项

- 只看第 0 通道；多通道信号的其他通道被忽略（但会原样直通）。
- 上报频率受 UI 轮询节奏限制，不是每块都发——它回答"波形长什么样"，不回答"每个样本是多少"。
- 实时安全：`process` 只做定长环形写入和 memcpy，无分配、无 IO；JSON 格式化发生在非实时线程（探针轮询时），不在音频回调里。

## 典型用法

```
signal_gen ──► biquad ──► probe_waveform ──► main_out
```

放在滤波器之后，直观对比滤波前后波形：正弦是否还是正弦、有没有相位畸变或削波。

## 实时安全

`process` 内仅环形缓冲写入与 memcpy，无 malloc/IO/锁；格式化与 JSON 编码只在 `get_param`（非实时线程）中执行。
