# orpheus.builtin.nlms — 归一化最小均方

## 功能

NLMS（归一化最小均方）自适应滤波器：逐样本用参考信号 `ref` 驱动一条 L 阶 FIR，输出 `y = w^T x`，并根据误差信号 `err` 在线更新系数 `w`。逐通道独立一套系数与延迟线。

### 直觉（以回声消除为例）

扬声器信号送进 `ref`，麦克风里"残留的、没被抵消掉的部分"送进 `err`。滤波器学着把 `ref` 变成"扬声器声音传到麦克风的回声副本"；学好了，`y` 就逼近真实回声，从麦克风信号里减去 `y` 后剩下的误差会越来越小——误差本身就是学费，NLMS 用误差反推系数该往哪调：

```
y[n] = Σ w[i] · x[n-i]                     （FIR 滤波输出）
w[i] ← leak · w[i] + mu · e[n] / (||x||² + eps) · x[n-i]   （系数更新）
```

`mu · e / (||x||² + eps)` 是"归一化"的含义：步长按参考信号当前能量自动缩放，输入大时自动小步走、输入小时不会停更，比固定步长的 LMS 稳健。

### `err` 引脚可空

`err` 不连接时，组件退化为**纯 FIR 滤波器**（系数冻结在当前值，只算 `y` 不更新）。代码里对 `err_buf == NULL` 做了判空分支。

## 端口

| id | 方向 | 说明 |
|---|---|---|
| `ref` | input | 参考信号，`channels` 通道（必须连接，否则报错） |
| `err` | input | 误差信号，`channels` 通道（可空：不连则冻结系数、纯滤波） |
| `out` | output | 滤波输出 `y = w^T x`，`channels` 通道 |

## 参数

| 参数 | 类型 | 默认值 | 范围 | update_policy | 说明 |
|---|---|---|---|---|---|
| `channels` | int | 2 | 1~64 | restart_required（影响签名） | 通道数，每通道独立系数 |
| `filter_length` | int | 32 | 1~4096 | restart_required（影响签名） | FIR 阶数 L，决定可建模的回声/路径长度 |
| `step_size` | float | 0.01 | 0.0~2.0 | restart_required | 步长 μ：越大收敛越快，过大（→2）会发散 |
| `leakage` | float | 1.0 | 0.0~1.0 | restart_required | 泄漏因子：<1 时系数每样本衰减，防漂移/爆系数 |
| `eps` | float | 0.000001 | 1e-12~1.0 | restart_required | 正则化：归一化分母保护项，防除零 |

### 关键参数详解

- **`filter_length`（L）**：要"学"多长的脉冲响应。回声消除中 ≈ 回声延迟时长 × 采样率（如 48 kHz 下 20 ms ≈ 960 阶）。L 直接决定 CPU 开销：process 复杂度 O(channels × frames × L)。
- **`step_size`（μ）**：经典范围 0.1~1.0；本组件默认 0.01 偏保守（稳、收敛慢）。μ→2 接近理论发散边界。
- **`leakage`**：1.0 = 无泄漏（标准 NLMS）。参考信号非持续激励（如静音段）时系数可能漂移，设 0.999 左右可让系数缓慢归零，换取鲁棒性。
- **`eps`**：||x||² 接近 0（静音）时防止 `mu·e/(norm+eps)` 爆炸。一般保持默认即可。

## 注意事项

- **所有参数都是 `restart_required`**：包括步长/泄漏/正则化——它们只在 `prepare` 时读入，运行时 set_parameter 返回 `ERR_UNSUPPORTED`。调参需停止后改值重跑。
- 系数/延迟线内存在 `prepare` 中 `calloc`（非实时线程），`destroy`/重新 `prepare` 时释放；`reset` 清零系数与延迟线，收敛过程从头开始。
- 输出是**滤波结果 `y`**，不是误差；做回声消除时"抵消后的干净信号"要在图里用加法器把 `y` 从麦克风中减掉（减完的那路再反馈回 `err`，形成闭环）。
- 内部用环形缓冲（`pos[c]` 写指针 + 取模索引）实现延迟线，无逐样本 memmove。

## 典型用法

```
speaker_ref ──► ref ┐
mic ──► [加法器: mic - y] ──► err ├─► nlms ──► out(y = 回声估计)
              ▲                   │
              └───────── y ───────┘（闭环：误差即抵消后信号）
```

## 实时安全

process 内无堆分配、无锁、无 IO（内存在 prepare 预分配）；只有乘加循环。注意 L 大、通道多时单块算力开销可观，需按 `channels × frames × L` 评估实时预算；`realtime_safe: true`。
