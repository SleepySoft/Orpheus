# orpheus.builtin.sine_mod — 正弦调制器

## 功能

用低频正弦波对输入信号做 AM（幅度调制）/ 颤音效果：

```
output = input * (1 + depth * sin(2π * freq_hz * t))
```

常用于给信号添加周期性音量起伏、Audiopilot 的慢速调制、或测试幅度调制链路。

## 参数

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `freq_hz` | float | 1.0 Hz | 调制频率。 |
| `depth` | float | 1.0 | 调制深度，范围 0~1。 |
| `channels` | int | 2 | 通道数，改变后需重新编译。 |

### `depth` 的真实含义

- `depth = 0`：无调制，输出 = 输入。
- `depth = 1`：调制范围从 0 到 2，输入会被完全关掉再放大到 2 倍。
- `depth = 0.5`：调制范围 0.5 ~ 1.5，较温和的颤音。

当 `1 + depth * sin(...)` 小于 0 时，组件会把它钳位到 0，因此不会出现相位反转。

### `freq_hz` 的选择

- 0.1~5 Hz：慢速颤音，常用于 Audiopilot 的噪声调制。
- 5~20 Hz：明显颤音，有“抖动”感。
- >20 Hz：进入低频 AM  territory，可产生和频/差频。

## 端口

- `in`: 输入音频，`channels` 通道。
- `out`: 输出音频，通道数与输入相同。

## 注意事项

- 调制深度较大时输出可能超过 1.0，建议后接限幅器或软削波。
- `freq_hz` 是 smoothed 参数，可以在运行时实时调；但 phase increment 是立即重新计算的，没有频率渐变过程。
- 相位在每个 process 块内连续累加，跨块不会跳变。

## 典型用法

```
signal_gen ──► sine_mod(freq_hz=2.0, depth=0.3) ──► out
```

给测试音加入 2 Hz 轻度颤音，用于验证链路幅度稳定性。
